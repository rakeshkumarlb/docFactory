On-Call Runbooks

These runbooks are for the on-call engineer. Acknowledge the page within 10 minutes and work through the steps in order.

RB-01 High API Error Rate

Alert: HighApiErrorRate. Symptoms: users see error pages or failed saves; 5xx rate above 2 percent

Diagnosis

  1. Check whether a deployment happened in the last hour.
  2. Open the API Overview dashboard and find the failing route.
  3. Check the logs of the failing service in Loki.

Actions

  1. If a deployment caused it, roll back using the SOP Roll Back a Release.
  2. If one service is failing, restart its pods one at a time.
  3. If the database is the cause, continue with RB-02.

Escalate: Page the Platform Team Lead after 30 minutes without improvement

RB-02 Database Connections Exhausted

Alert: DatabaseConnectionsExhausted. Symptoms: requests time out waiting for a connection

Diagnosis

  1. List the longest running queries in PostgreSQL.
  2. Check which service holds the most connections.

Actions

  1. Cancel the runaway query.
  2. Restart the service that holds the connections.
  3. Raise the pool size temporarily only with the Platform Team Lead's approval.

Escalate: Page the Database Administrator

RB-03 Matching Queue Backlog

Alert: MatchQueueBacklog. Symptoms: new matches appear late; queue depth rising

Diagnosis

  1. Open the Matching Pipeline dashboard.
  2. Check the worker count and the job duration.

Actions

  1. Scale the Matching Engine workers up by 4 replicas.
  2. If one job type fails repeatedly, move its messages to the dead-letter queue.

Escalate: Notify the Matching Team in the morning if the backlog cleared; page them if it did not clear in one hour

RB-04 Partner Sync Lag

Alert: SyncLagHigh. Symptoms: vacancies appear late on jobs.ps

Diagnosis

  1. Open the Partner Sync dashboard.
  2. Check whether the partner API returns errors.

Actions

  1. If the partner API is down, wait and inform the service desk.
  2. Otherwise run the Run Partner Sync Backfill procedure.

Escalate: Integrations Team lead during business hours

RB-05 Backup Failed

Alert: BackupFailed. Symptoms: a nightly backup job reports failure

Diagnosis

  1. Read the backup job log.
  2. Check free space on the backup storage.

Actions

  1. Rerun the backup job.
  2. If storage is full, remove expired backups according to the retention policy and rerun.

Escalate: Operations Manager if two nights in a row fail
