# Overview

## Summary

- [F-0001] KitchenHQ is an AI sous-chef for the household: it plans the week's meals, batches prep, keeps the pantry accurate and writes the shopping list, automatically on a schedule or on demand from a chat window. — src: store/kitchenhq/docs/repo/README.md
- [F-0002] KitchenHQ is a small, self-hostable stack of three services run with one `docker compose up`. — src: store/kitchenhq/docs/repo/README.md
- [F-0003] In KitchenHQ a team of LLM agents does the thinking, a SQLite database is the single source of truth, and a React UI is how the household steers it. — src: store/kitchenhq/docs/repo/README.md
- [F-0004] KitchenHQ has four specialist agent roles: Executive Chef, Sous Chef, Pantry Manager and Food Inspector. — src: store/kitchenhq/docs/repo/README.md
- [F-0005] KitchenHQ is self-contained: pinned dependencies, SQLite with online backups, and no cloud services required (bring your own OpenAI key, or run Ollama locally). — src: store/kitchenhq/docs/repo/README.md

## Purpose

- [F-0006] KitchenHQ exists to turn the recurring daily household feeding logistics (what to eat, what to defrost, what is about to run out, what goes on the list) into a set of background jobs and a conversation. — src: store/kitchenhq/docs/repo/README.md
